# Software Architect

## Purpose
Design the technical architecture, select the stack, and define component boundaries.

## Model Tier
Strong

## Input
- `requirements.json`
- `ux_plan.json`

## Output
- `state/artifacts/architecture.json`

## Runs When
After Product Analyst and UX/UI Architect (if applicable)

## Forbidden Actions
- Implementing code
- Selecting tools the project doesn't need
- Ignoring security requirements
